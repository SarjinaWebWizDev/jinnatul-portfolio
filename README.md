# Shaikh Jinnatul — Portfolio
React + Vite + Tailwind CSS + Framer Motion.

    npm install
    npm run dev      # local preview
    npm run build    # production build in dist/

Deploy: push to GitHub, import the repo in Vercel (Framework: Vite). Build command `npm run build`, output `dist`.

Content lives in `src/data.js`; images in `public/images/{profile,projects,certificates}`.
